## Проверка целостности

В [manifest.json](manifest.json) записаны размер каждого файла, разрешение, SHA-256 и Git blob SHA. При переносе проверены SHA-256 исходных PNG и SHA созданных объектов Git. Файлы в репозитории должны совпадать с этими значениями.

Не заменяйте оригиналы миниатюрами, изображениями из предварительного просмотра или повторно сжатыми версиями. Небольшой размер карточки в README не требует уменьшать сам файл: нажатие открывает оригинал.
