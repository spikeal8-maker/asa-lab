# ASA Lab

Образовательная платформа для виртуальных лабораторий, управления классами и учебными проектами.

## Назначение

ASA Lab проектируется как единая школьная платформа, в которой общее ядро Classroom Core управляет классами, педагогами, учениками, заданиями, проектами, версиями работ, проверкой и безопасным доступом.

Первый предметный модуль — виртуальная лаборатория электроники. В дальнейшем к тому же ядру можно подключать шахматы, программирование, робототехнику и другие учебные среды.

## Текущий статус

Репозиторий создан и подготовлен для размещения продуктовой спецификации и последующей разработки.
