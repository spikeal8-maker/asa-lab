# Поиск, страницы, погода и картинки

Интернет-поиск работает через сервер ASA и бесплатный компонент SearxNG. Пользователю не нужно устанавливать расширение или вводить платный поисковый ключ. В плюсике у поля ввода можно выбрать режим поиска; «Выключен» запрещает новые обращения к интернету для этого запроса. «Авто» позволяет выбрать действие по смыслу вопроса в пределах доступных адаптеров.

web_search возвращает список ссылок и выдержки поисковика. Это ещё не чтение полного сайта. Модель с подключёнными инструментами может выбрать read_page для конкретных источников. Прямую HTTPS-ссылку из сообщения также можно прочитать: попросите кратко разобрать страницу. Возвращается ограниченный текст и доступные изображения. До двух проверенных растровых картинок передаются модели с Vision в пределах оставшегося бюджета вложений. Получение подписи картинки не означает просмотр её пикселей.

Чтение сайта не является полноценным браузером: JavaScript не выполняется, вход в чужие аккаунты не производится, локальные и приватные адреса недоступны. Страница может запретить получение данных или оказаться недоступной. Помощник обязан сообщить об отказе и не выдавать заголовок или сведения по памяти за прочитанный текст.

В «Админ → ИИ → Интернет-поиск» настраиваются количество результатов (1–12), число читаемых страниц (0–2), объём текста одной страницы (500–8000 символов), часовой лимит, разрешённые и исключённые сайты, дополнительные инструкции и погода. Ноль страниц запрещает чтение страниц. Эти параметры применяются к новым запросам. Исключения сайтов важнее разрешений.

weather получает прогноз для указанного города из MET Norway и использует OpenStreetMap для поиска места. Неоднозначный город требует уточнения. В ответе должны быть источник и время данных; отсутствие результата нельзя заменять выдуманным прогнозом. Погода не требует ключа Яндекс.Погоды.

image_search ищет существующие картинки, а generate_image создаёт новую. Картинки поиска показываются галереей: нажмите для увеличения; копирование, скачивание и «Использовать в чате» доступны у карточки. При доступности источника действия получают файл по сохранённому адресу источника; это не гарантирует максимальное разрешение или право свободного использования. Если оригинал недоступен, миниатюра предлагается явно. Порядок результатов задаёт поисковик с фильтрацией и удалением дублей; это не визуальная проверка всех картинок моделью.
