# Чат ASA Lab

Напишите вопрос в разделе «ИИ» и отправьте его кнопкой со стрелкой или Enter. Shift + Enter добавляет новую строку. Во время ответа кнопка остановки прерывает текущую генерацию; поле ввода позволяет готовить следующий вопрос. Новый диалог создаётся отдельно от текущего.

Выбор модели находится рядом с полем ввода. Пользователю доступны только модели, разрешённые администратором и правилами доступа. Модель по умолчанию, порядок, доступность и бюджеты настраиваются в «Админ → ИИ → Настройки». Подключения и ключи меняет администратор во вкладке «Подключения». Помощник не видит ключи и не меняет эти настройки по текстовой просьбе.

Через плюс добавляются изображения и файлы. Поддерживаются проверяемые PNG, JPEG, WebP и разрешённые текстовые форматы. Произвольные PDF, Office, архивы и другие форматы нельзя обещать прочитать без подтверждённой поддержки. Несколько вложений допустимы в пределах лимитов интерфейса. Вставка из буфера может добавить изображение или файл вместе с текстом.

Распознавание содержимого картинки требует модели с Vision. Если выбранная модель не поддерживает изображения, нужно выбрать поддерживающую модель; помощник не должен угадывать картинку по имени файла. Поддержка определяется серверным каталогом или подтверждёнными возможностями локальной Ollama.

У сообщений есть действия копирования; своё сообщение можно перенести в поле ввода для изменения. Копирование показывает временную зелёную галочку и остаётся доступным повторно. Ответ и блоки кода можно скачать предлагаемыми кнопками. Помощник не записывает файл на компьютер самостоятельно.

Эта справка описывает интерфейс и ограничения версии сборки. Текущая доступность конкретной модели, соединения, бюджета или личного файла проверяется отдельными механизмами и не следует из справки.
