# Отчёт OBS-015 — классификация журналов всех редакторов

Дата: 2026-10-14. TASK-OBSERVABILITY-001 / #551. ТЗ 1.12, раздел 20. Первый пункт разрешённой серии 15 → 16 → 17.

## Причина и изменения

Воспроизведено: blocks/3D/chess/checkers превращались в portal/api, импорт принимал прежний неполный перечень модулей, старые client_diagnostic могли принудительно стать ERROR, а старые допустимые по форме подсказки каталога мешали правильному фильтру. В админке отсутствовали варианты 3D, шахмат и шашек.

Исправлены общие правила Python/TypeScript, alias blocks→scratch, импорт уровней, классификация старой истории до поиска/выгрузки и метаданные коллектора. Добавлены три варианта существующего фильтра админки. Самопроверка также воспроизвела потерю классификации при усечении длинного JSON; классификация теперь определяется до усечения и сохраняет известные подсказки при нечитаемом усечённом JSON. Приоритет системных источников и очистки БД сохранён.

Девять файлов: tools/collect_logs.py, tools/test_collect_logs.py; apps/api/src/log-subsystems.ts и .spec.ts; apps/api/src/admin-logs.worker.ts и .spec.ts; apps/api/src/admin-logs.controller.ts; apps/web/src/admin/AdminLogsPage.tsx; apps/web/src/admin/testing/admin-log-modules.spec.ts.

Оригинальные сегменты, ID, контроль целостности и права сохранены. Запрос/ZIP не переписывают каталог и сегменты; сборщик исправляет только метаданные классификации. Схемы производителей пользовательской телеметрии не расширялись: поддержка классификации пяти имён не означает появления новых браузерных событий во всех пяти редакторах.

## Приёмка и ограничения

Первый независимый критический просмотр a5aab962: NEEDS_FIX. Импорт удалял подсказку subsystem, поэтому усечённая запись chess превращалась в подсистему api. Узкий probe воспроизвёл дефект, ID/WARN и оригинал сохранились. Исправление сохраняет допустимую подсказку редактора только для api/web; host и известные источники БД продолжают классифицироваться по собственным правилам. Новый тест воспроизвёл два падения raw/gzip; после правки проверены все пять редакторов, уровни, ID, оригинальные архивы и отрицательные host/DB/unknown случаи. API/UI не менялись и их PASS переиспользован. Свежий окончательный независимый просмотр точного 90ed4576: PASS. Отдельные raw/gzip import → query → ZIP probes, web/blocks alias и source/provenance controls прошли; manifest всех девяти файлов совпал. Уже пройденные suites не повторялись. POST_STEP_REVIEW: L2_DOMAIN_MUTATION и L1_UI_BEHAVIOR; layout impact — только три option labels существующего select, CSS и DOM структура сохранены.

Не выполнялись полная локальная сборка/repository gate, реальная рабочая БД, Docker, Linux journal, школьный сценарий, hydrated SPA и owner visual acceptance. Две большие worker проверки пропущены явно. Браузерная схема client_diagnostic по-прежнему содержит прежние четыре модуля; расширение producers относится к последующим пунктам. CI отражается отдельно по точному опубликованному SHA, не выводится из локального PASS.
