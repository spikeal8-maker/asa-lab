## Scope decisions for operations

Organization membership controls do not widen the full Account content reader.
Platform administrators may manage organization roles, including owner, while
preserving the last active owner. Organization owners manage only non-owner
memberships; school administrators manage only member/educator memberships and
cannot modify administrative memberships or promote themselves. Personal
workspaces are excluded. Class co-teacher operations preserve existing educator
eligibility, active Account, five-colleague limit and canonical legacy links;
primary ownership is unchanged. These are explicit conservative control rules,
not a new global user-role hierarchy.

Operations is decomposed into three coordinated independent authoring slices:
export/project-view integration, retained Seat detail/notes, and scoped membership
commands. Each has separate paths/migration allocation, followed by one combined
independent challenge and exact-source integration gate. No nested delegation
beyond these three authors is selected.

For acquisition, the accepted conservative design is a separate authenticated
observation pipeline; canonical visit delivery stays unchanged. Only controlled
source/medium/campaign slugs from the current document are observed, with no raw
URL/query, fingerprinting, cross-account stitching or historic reconstruction.
Observation retention is explicitly 90 days, enforced in readers and bounded
cleanup; receipt retention is separate. UI must distinguish these browser claims
from actual authentication methods and disclose unknown/expired coverage.
