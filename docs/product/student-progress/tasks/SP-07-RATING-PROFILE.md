# SP-07 — общий рейтинг в личном интерфейсе

**Зависимости:** SP-03, SP-06. **Класс:** L1 UI; L3 при добавлении межконтекстной safe-scalar выдачи.\
**Нормы:** MASTER SP-D02, SP-D03, SP-D12…SP-D15, SP-D21…SP-D24.

## Результат

Рядом с главным аватаром показан настоящий общий рейтинг, источник «За всё время» и раскрытие понятной истории. Публикации вносят объяснимый вклад. Человек видит один результат при обычном входе в свой Account.

## Scope и действия

1. Подключить server total/rule version/coverage к существующему личному блоку.
2. Показать источники и записи истории без внутренних идентификаторов и недоступных private объектов.
3. При наличии достоверной истории допустим period delta с точно определённой границей времени; без неё прирост отсутствует.
4. Определить и проверить safe-scalar policy для Seat связанного человека. Она не выдаёт Account-private проекты и другие группы. Если безопасный общий scalar не выпускается, показывается честно scoped результат профиля; это не объявляется общей cross-context поддержкой.
5. Нулевой результат содержит доступный первый шаг, а не ложный уровень или искусственную награду.

## Приёмка

Тот же Account после разных разрешённых способов входа имеет тот же общий результат. Отмена/коррекция объяснима. Scope меняется только серверно; delayed response и logout очищают прежние данные. History total/источники совпадают с ledger; нет суммы групповых score. Общий рейтинг не выдаёт права.

Layout проверяется в настоящей главной и раскрытии на 1440/1024/390/320, с большими числами, отсутствием истории, loading/error и 200% zoom. Если добавлялся scalar для Seat, обязательны denied/cross-tenant/revoked tests и independent challenge review.

## Выход

Верхний блок принятого референса работает с реальным рейтингом и статистикой. История не показывает недоступные пользователю объекты, макетные числа и неподтверждённый рост.
