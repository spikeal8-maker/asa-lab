# SP-05 — калибровка и фиксация общего рейтинга

**Зависимость:** SP-02, словарь источников DATA contract. **Тип:** bounded расчёт и versioned product decision.\
**Нормы:** MASTER SP-D03, SP-D05, SP-D12…SP-D15, SP-D20…SP-D22.

## Результат

Одна полностью числовая версия правил с весами, ограничениями, округлением, ключами зачёта, правилами исправления и исторического импорта. Результат готов к исполнению SP-06 без самостоятельного выбора коэффициентов разработчиком.

## Вход и метод

1. Проверить конкретные canonical источники accepted learning result, completion, первой публикации и действующей реакции. Составить source mapping с ID и отменой/коррекцией.
2. Составить три полностью определённые кандидатные конфигурации. Никаких уровней, валют, новых ролей, прав за общий рейтинг или новых мотивирующих механик.
3. Выполнить чистый dry-run на deterministic synthetic fixtures и доступных обезличенных агрегатах. Live mutations, создание фиктивных пользовательских баллов и изменение прав запрещены.
4. Выбрать один кандидат по критериям ниже; записать причины и точные expected totals каждого fixture.
5. Сохранить versioned machine-readable rule table и decision report в точном плане SP-05. Их формат и checksum фиксируются перед SP-06.

## Обязательные профили

Новичок; ученик с одним занятием в неделю; ученик без публикаций; взрослый автор без группы; одна содержательная работа; много технических дублей; Scratch/robotics без copy operation; 3D/electronics с copies; один результат через несколько groups/links; снятие/возврат лайка; собственные и повторные копии; позднее связывание двух identities; отозванная/скрытая публикация; исправленный учебный результат.

## Критерии выбора

- Истинный ноль при отсутствии зачтённых результатов.
- Учебный прогресс возможен без отклика и права публиковать.
- Самостоятельный автор имеет путь без школьного членства.
- Копирование не является обязательным источником: в v1 до надёжной qualified-recipient модели его рейтинговый вес равен нулю, реальная статистика сохраняется.
- Увеличение числа технических дублей, self-actions и повторной доставки не меняет сумму.
- У одной публикации ограничен вклад реакций. Предел указан именно на публикацию, без ложного обещания доли во всём балансе.
- Вес подтверждённой работы больше веса одиночного лайка; все коэффициенты и границы имеют проверяемые примеры.
- Нет награды за login, idle time, клики, raw save и количество комментариев.
- Нет начисления за произвольную custom merit без общего проверяемого критерия.
- За календарный перерыв итог не уменьшается; объяснимые коррекции работают.
- Изменение количества учебных групп не создаёт баллы.

## Граница завершения

Если нет достоверного источника для вида вклада, этот источник явно выключается в версии правил; не заменяется косвенным признаком. Независимый рецензент проверяет выбранную таблицу и fixtures. Пока не осталось ровно одной принятой версии, SP-06/SP-07 не включают публичный общий балл. Вопрос численных весов закрывается этим этапом, а не остаётся TODO внутри frontend.
