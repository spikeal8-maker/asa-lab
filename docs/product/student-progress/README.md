# ASA Lab — личный прогресс ученика и автора

**Программа:** ASA-STUDENT-PROGRESS-001. **Редакция:** 1.0.\
**Основание:** принятая владельцем 11 ноября 2026 года компактная композиция и поручение подготовить систему ТЗ для её внедрения.\
**GitHub:** [Issue #1090](https://github.com/spikeal8-maker/asa-lab/issues/1090).

## Начало работы

1. Прочитать `AGENTS.md`, получить свежий preflight и выбранный этап направления `student-progress` из [`current.yaml`](../../execution/current.yaml).
2. Открыть [основное ТЗ](MASTER_SPEC.md), затем только выбранную карточку из [плана реализации](IMPLEMENTATION_PLAN.md).
3. Прочитать указанные в карточке разделы контрактов и сценарии [приёмки](ACCEPTANCE.md).
4. Выполнить один ограниченный этап, его проверки и review. Передать контроллеру фактический результат.

Документы описывают требуемый продукт. Активная задача, SHA, CI, checkpoint и готовность находятся только в `docs/execution/current.yaml`. Порядок этапов сам по себе не является отчётом о выполнении.

## Что должно появиться

Главная показывает собственный аватар, достоверные результаты публикаций и накопленный общий рейтинг после реализации его расчёта. Учебные группы представлены компактными рядами: свой аватар слева крупнее, место поверх изображения сверху слева, рейтинг снизу справа, остальные участники — без имён. Условия доступа объясняют конкретное действие и рейтинг конкретной группы.

Оболочка ASA Lab, верхняя панель, меню и поиск сохраняются. Общий рейтинг не складывается из рейтингов групп. Демонстрационные числа референса не переносятся в продукт.

## Связь с существующими нормами

Эта программа детализирует [ученический интерфейс](../ASA_STUDENT_EXPERIENCE_SPEC.md) и [центр обучения](../learning/ASA_LEARNER_LEARNING_HUB_SPEC.md). Она не заменяет Learning Master, identity/access contracts, публикационный runtime или правила установки. Если обнаружена коллизия, исполнитель фиксирует конкретные нормы и передаёт её контроллеру до изменения соответствующего поведения.

Снимок HTML служит визуальным ориентиром. Продуктовую приёмку подтверждают реальные страницы ASA Lab, настоящие разрешённые API и synthetic fixtures по `ACCEPTANCE.md`.
