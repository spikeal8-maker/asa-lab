# D2–D4: три светодиода в правильном порядке

Учебный пример для промежуточного выпуска ASA Lab: три красных светодиода по очереди управляются обычными digitalWrite() и delay(). Нужны Arduino Uno, три резистора по 330 Ом и три обычных красных LED. Каждый светодиод имеет собственный токоограничивающий резистор.

## Статус примера

Этот материал подготовлен для среза Issue #649. Принятый выпуск D13 служит его основой; фактическая браузерная приёмка именно схемы D2–D4 ещё не зафиксирована. Описанное ниже поведение — проверяемый результат урока, а не сообщение об уже выполненном испытании или обновлении школьного сайта. Результаты приёмки, точный SHA и статус main публикуются отдельно в карточке среза.

## Схема

Файл [D2_D4_3x330ohm_red_LED.schematic.json](../examples/D2_D4_3x330ohm_red_LED.schematic.json) содержит полное описание схемы: семь компонентов, девять проводов и первую программу 100/100 мс. Сверьте с ним собранную схему в редакторе.

| Выход Uno | Резистор | Светодиод | Обратный провод |
| --- | --- | --- | --- |
| D2 | R1, 330 Ом: lead-1 со стороны Uno, lead-2 со стороны LED | LED1: анод к R1 | Катод LED1 → GND Uno (power-gnd-1) |
| D3 | R2, 330 Ом: lead-1 со стороны Uno, lead-2 со стороны LED | LED2: анод к R2 | Катод LED2 → GND Uno (power-gnd-1) |
| D4 | R3, 330 Ом: lead-1 со стороны Uno, lead-2 со стороны LED | LED3: анод к R3 | Катод LED3 → GND Uno (power-gnd-1) |

Всего в каждой ветви три провода: выход → резистор, резистор → анод, катод → GND. Проверьте полярность по контактам anode и cathode в схеме. Свет должен зависеть от этой электрической цепи; при разрыве цепи или обратной полярности правильного свечения ожидать нельзя. Не соединяйте выход Uno прямо со светодиодом без резистора.

В этих программах D13 не используется: встроенный индикатор L на Uno должен оставаться погашенным.

## Что наблюдать

Читайте состояние тройкой в порядке D2, D3, D4: 1 означает свет, 0 — отсутствие света. Правильная повторяющаяся последовательность:

**100 → 000 → 010 → 000 → 001 → 000 → 100 → …**

Сначала светится LED1 на D2, затем наступает общая пауза, далее LED2 на D3, снова общая пауза, затем LED3 на D4 и ещё одна общая пауза. Одновременно должен светиться только один из трёх LED. Наличие всех трёх вспышек само по себе недостаточно: проверьте их порядок и все промежуточные состояния 000. Сосчитайте не менее восьми полных кругов, от очередного включения D2 до следующего включения D2.

Здесь highMs — длительность свечения очередного LED, а offMs — общая пауза после него. Это не полное время, пока конкретный LED выключен: он также ждёт прохода двух остальных ветвей.

## Общий учебный темп

В промежуточном выпуске используется общий темп симуляции 0,125: одна секунда модельного времени соответствует примерно восьми секундам на экране. Все три ветви должны относиться к одному моменту симуляции и сохранять относительную длительность фаз. Для настоящего Arduino такое замедление не требуется; значения delay() в программах по-прежнему заданы в миллисекундах модельного времени.

| Программа | Номинально на экране при темпе 0,125: вспышка / общая пауза | Номинальный полный круг D2 → D3 → D4 |
| --- | --- | --- |
| 100/100 мс | 0,8 / 0,8 с | 4,8 с |
| 200/200 мс | 1,6 / 1,6 с | 9,6 с |
| 300/300 мс | 2,4 / 2,4 с | 14,4 с |
| 150/150 мс | 1,2 / 1,2 с | 7,2 с |
| 100/300 мс | 0,8 / 2,4 с | 9,6 с |

Числа в таблице получены расчётом при выбранном темпе, это не измерения проведённого браузерного испытания. Для урока существенны различимость темпов, правильный порядок и сохранение соотношений. Программа 200/200 должна давать приблизительно вдвое более длинный круг, чем 100/100, а 300/300 — втрое; 150/150 должна оказаться между 100/100 и 200/200. В варианте 100/300 общая пауза после каждой вспышки втрое длиннее самой вспышки.

## Полные программы

Остановите моделирование перед заменой программы. В текстовом редакторе Arduino заменяйте весь скетч на соответствующий полный вариант ниже, затем запускайте моделирование. Для сравнения оставляйте ту же схему и тот же общий темп. Если замена кода не меняет наблюдаемую скорость или нарушает порядок, результат не соответствует этому примеру.
### 1. Исходный темп: 100 мс свечения и 100 мс паузы

```cpp
const int highMs = 100;
const int offMs = 100;

void setup() {
  pinMode(2, OUTPUT);
  pinMode(3, OUTPUT);
  pinMode(4, OUTPUT);
  digitalWrite(2, LOW);
  digitalWrite(3, LOW);
  digitalWrite(4, LOW);
}

void loop() {
  digitalWrite(2, HIGH);
  delay(highMs);
  digitalWrite(2, LOW);
  delay(offMs);

  digitalWrite(3, HIGH);
  delay(highMs);
  digitalWrite(3, LOW);
  delay(offMs);

  digitalWrite(4, HIGH);
  delay(highMs);
  digitalWrite(4, LOW);
  delay(offMs);
}
```

## Остановка, Reset и сохранение

1. Во время последовательности нажмите «Остановить моделирование». Мигание должно прекратиться без продолжения старой очереди вспышек. При последующем запуске проверяйте программу, которая сейчас открыта в редакторе.
2. На последней программе 100/300 выполните Reset через штатное действие редактора. Программа должна начать проход заново: исходное погашенное состояние, затем D2 → пауза → D3 → пауза → D4 → пауза. Проверьте ещё восемь полных кругов и погашенный L на D13.
3. Дождитесь завершения штатного сохранения проекта после последнего редактирования. Если автосохранение уже завершилось, не изменяйте код специально ради повторного сохранения. При наличии доступного ручного сохранения можно использовать его обычным способом.
4. Закройте и снова откройте сохранённый проект. Сверьте все три ветви и полный скетч 100/300; после запуска должен воспроизводиться тот же порядок и те же соотношения длительностей. Для независимой проверки сохранения используется новый браузерный контекст с одними только cookies входа, без переноса локального состояния редактора.

Для каждой программы отдельно отметьте порядок D2 → D3 → D4, общие паузы, различимость темпа и состояние индикатора L. Отдельно отметьте повторение результата после Reset и после повторного открытия сохранённого проекта. Эти наблюдения относятся к конкретной испытанной версии редактора; перенос изменений в main сам по себе не подтверждает обновление установки, где проходит урок.
