# Сохранённый эксперимент NPN-кэша

По прямому запросу владельца все наработки этого среза сохранены в main.
Рабочие функции Arduino и счётчики уже активны с `242d401f`.

Этот эксперимент новых пользовательских возможностей не добавляет:
при побайтно одинаковом контрольном результате он оказался на 7,6% медленнее.
Поэтому его исходный diff хранится в `source.patch.gz`, а не включён в runtime.
`manifest.json` фиксирует исходный и базовый SHA и проверенные хеши архива.
Полные [измерения и результаты](../../evidence/npn-reuse-833/README.md)
также находятся в main; ветка кандидата сохранена отдельно.

Независимый read-only review подтвердил статус NOT READY. Тесты принятия,
браузер, общий gate и лимиты для этого эксперимента не запускались: ускорение
не доказано. Это сохранение работы, не исправление производительности.
