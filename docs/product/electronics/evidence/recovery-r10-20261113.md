## Candidate boundary

This bounded repair removes the two synchronous stopped-editor preflights and
reuses one asynchronous accepted result for diagnostics and ordinary LED resource
preparation. The existing Worker preflight also stops performing a second full
solve merely to check result metadata. The complete direct preflight result is
preserved, including transient and controller state.

`stopped-simulation-preflight.ts` owns the input key, committed session lifecycle,
one in-flight request, one latest pending input, and an eight-entry cache of
previously accepted results. The key combines the canonical electrical digest,
every Uno program (component-type or variant identification), installed model-set
digest, engine revision, Worker protocol and project-session identity.

Geometry, annotations and wire presentation do not invalidate that electrical
result. Nominal values, connections, physical LED colour/profile and Arduino
sources do. An unfinished old request in A → B → A is not an accepted cache hit.
Current transport failure ends pending with an explicit technical error. Stopped
diagnostics never substitute a persisted result matched only by electrical digest.

The hook sends only committed inputs. Loading/error, project replacement,
Start/Stop and unmount invalidate the old stopped session. Normal autosave remains
separate from document loading. The running controller, canonical clock and
source-only running-update contract are unchanged. Stopped
`calculateLiveSimulation` remains the existing persisted-result projection.
