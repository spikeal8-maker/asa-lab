# One Uno, one to four display counters

The `.ino` files are the actual sketches used by the native verification:

- `N-linear.ino`: linear text without user helper functions.
- `N-functions.ino`: real scalar-parameter void helpers, nested calls and scan waits.
- `N-blocks-generated.ino`: generated by a genuine connected Blockly workspace.

N is 1–4. One common-cathode indicator per digit shares eight segment buses;
each digit has an NPN common driver. Segment resistors are 2.2kΩ; base resistors
are 1kΩ. The reusable physical topology is built by
`contexts/electronics/testing/fixtures/arduino-seven-segment-matrix.ts`.

Counters start at 8, 98, 998 or 9998, show all nines, then wrap to zero. They scan
each digit for 2ms and update the value using millis rather than adding a long
blocking wait. The four-display screenshots show physically integrated emission.

See [full evidence and limits](../../evidence/arduino-void-functions-824/README.md).
All 24 code/count/viewport cases passed their native counter assertions. The
simulation currently runs slower than realtime; requirement 3 remains open.
These files do not prove installed server saving, user import or firmware-toolchain
compilation. No AVR compiler was installed or invoked by this slice.
