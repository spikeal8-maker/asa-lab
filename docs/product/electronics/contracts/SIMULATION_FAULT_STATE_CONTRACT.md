# Классы остановки моделирования (#463)

Этот контракт описывает наблюдаемое состояние одного запуска. Электрическую истину
определяет engine; UI не преобразует неуспешный результат в `solved` и не
приписывает схеме отказ Worker.

| Источник | Класс и код | Переход | Видимый результат |
| --- | --- | --- | --- |
| Успешный preflight и первый `ready` advance | `solved` | `starting → running` | Показания и время последнего подтверждённого горизонта. |
| Поддерживаемая разомкнутая/непитаемая цепь | `invalid`, `no_source`/`open_circuit` | `starting → running` после `ready`; намеренный Stop → `stopped` | Диагностика состояния схемы; нулевой/отсутствующий расчёт не выдаётся за рабочий ток. |
| Preflight без модели или со срывом численной проверки | `unsupported`/`nonconvergent` и исходный diagnostic code | `starting → stopped` | Причина схемы без сообщения об отказе Worker и без частичного успешного результата. |
| Scheduler fault | `electrical_sample_failed`, `electrical_quality_failed`, `physical_advance_failed`, `arduino_execution_failed` и прочие исходные коды | `starting/running → stopped` | Электрический, физический или runtime класс; ошибочный future frame не показывается. |
| Worker creation, request, protocol, execution или timeout | Исходный protocol code либо типизированный код client failure | `starting/running → stopped` | Технический класс и предложение запустить снова; новый Start создаёт новое поколение на актуальном документе. |
| Намеренный Stop или добавление детали | Без fault | `starting/running → stopped` | Сообщение о техническом отказе не появляется; документ остаётся редактируемым. |
| Ответ старого поколения | Stale response | Без перехода текущего поколения | Старый результат и его ошибка не меняют новый запуск. |

`yielded` сам по себе не означает готовый электрический кадр. Видимое время
моделирования обновляется только после подтверждённого `ready` advance; при
неответившем Worker остаётся прежним до ограниченного timeout и Stop. Fault
останавливает runtime, но не меняет документ, историю, локальную черновую копию
или сохранённую ревизию.
