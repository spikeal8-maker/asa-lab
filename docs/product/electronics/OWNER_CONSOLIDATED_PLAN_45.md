# ASA Lab Electronics — объединённый план из 45 пунктов

Стабильная нумерация списка, согласованного с владельцем 26 октября 2026 года.
Фразы «пункт 1», «пункт 2» и далее относятся к этой таблице. Исходные 23
замечания сохраняют собственные номера в [старой очереди](OWNER_23_EXECUTION_QUEUE.md).
ASA Lab предназначена для обучения и обычного проектирования: проверяется
достоверное поведение собираемых схем, а не только демонстрационный пример.

Это каталог требований, **не второе execution state**. Выбранная задача,
статус, SHA и evidence находятся только в
[current.yaml](../../execution/current.yaml), в Electronics lanes. Исторический
журнал — [Issue703](https://github.com/spikeal8-maker/asa-lab/issues/703).
Каждый новый срез выбирается отдельно; наличие строки не разрешает автоматически
начинать её. Источники, интерфейс, установленная версия и приёмка владельцем
подтверждаются отдельно. Сервер не обновлять без отдельного поручения.
