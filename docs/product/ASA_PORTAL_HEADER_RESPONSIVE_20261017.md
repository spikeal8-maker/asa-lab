# ASA Lab — единая верхняя шапка

## Область действия
Общая шапка авторизованного PortalShell для преподавателя и ученика. Не меняется публичная страница входа, редакторы, API, права или функциональность кнопок. Стили находятся в apps/web/src/creator-portal/portal-header-adaptive.css, подключены после других общих стилей в App.tsx. В Classroom CSS больше не переопределять сетку portal-header: специфические дубли удалены.

## Адаптивный контракт
- Все ширины в CSS-пикселях с учётом Windows DPI и Chrome zoom.
- 320–1920: одна строка 56 px, без скачков на 1023/1024.
- 601–1023: меню, бренд, «Проекты», «Знания», «Создать», аватар в одной строке, полные подписи двух разделов видимы.
- 380–600: разделы показываются доступными 44px иконками со скрытым визуально текстом для экранных дикторов.
- До 560: «Создать» — 44px кнопка с видимым плюсом, список создания помещается в окно.
- До 379: текст бренда скрыт, иконка бренда и мобильное меню остаются.
- 1921–3840 CSS px: высота растёт до 72 px, шрифты навигации 16→20 px, бренд 22→26 px.
- Стандартный скроллинг продолжает работать; визуальная полоса прокрутки окна PortalShell скрыта.

## Приёмка
- Проверяются 320/360/390/430/540/600/601/680/768/820/900/1023/1024/1097/1250/1440/1920/2560/3840.
- Геометрия без наложений текста, надписей, иконок, бренда, кнопки создания и аккаунта; мобильное и create-меню не выходят за экран.
- aria-label «Проекты» / «Знания», возврат фокуса, Escape, закреплённость при скролле.
- Одни правила на страницах классов, галереи и знаний.
- Тест: e2e/portal-header-responsive.spec.ts; отчёт CI в Portal Header Responsive.
- Снимки собранного UI и отдельные снимки реального Docker preview не смешивать.
