# ASA Lab — компактная страница открытого класса преподавателя

## Границы
Только открытый класс преподавателя (шапка класса, восемь вкладок, реестр учащихся, два режима журнала). Без изменений данных, API, SQL, безопасного режима, паролей, настоящих кодов доступа, системы сохранения, Scratch, Electronics и общих модулей. Продолжает компоновку «Мои классы», зависит от PR #582 и общего header PR #585.

## Контракт компоновки
- Возврат «Мои классы» и заголовок конкретного класса рядом. Пять показателей, код класса и действие «Поделиться» остаются со своими обработчиками, компактно рядом или во втором ряду по реальной ширине контейнера.
- Все восемь вкладок и действия «Добавить ученика», «Добавить списком», «Карточки доступа», «Коды», поиск располагаются в общей адаптивной панели, без лишнего внешнего обрамления. На малых экранах используется существующий selector раздела класса; действия и поиск плотными рядами.
- Названия учащихся кликабельны и открывают уже существующий ClassroomStudentPage. Теперь тот же переход доступен по имени из ручного журнала по датам и журнала назначенных заданий.
- Таблица 680+ CSS px рабочей области, более плотная двухъярусная строка при меньших ширинах. Коды учеников остаются скрытыми по умолчанию, сами кнопки не растягиваются на высоту строки; меню из трёх точек без постоянной серой заливки.
- Матрицы журнала имеют локальную горизонтальную прокрутку, в ручном журнале сохраняется закреплённый первый столбец. Никакие школьные оценки и автоматическая запись оценок не меняются.
- На телефоне нельзя сжимать заголовок и поиск до нечитаемой ширины или уводить за экран действия.
- 4K для открытого класса подчиняется адаптации по CSS-пикселям, с учётом ОС/масштаба браузера.

## Проверки
- 320/390/540/680/768/900/1024/1440/1920, 15 заполненных учеников, визуальные PNG и измерения actual container.
- Доступность добавления, поиск, восемь разделов, имя ученика → профиль → назад, журнал → имя → профиль → назад; нет изменений базы в синтетическом тесте.
- Полный существующий Classroom UI-прогон 120 сценариев и отдельный CI workflow Teacher Open Classroom Layout.
- Визуальная приёмка на реальном Docker preview 127.0.0.1:4620 с восстановленной копией PostgreSQL и маскированием ученических/классных кодов обязательна перед переходом в main.
