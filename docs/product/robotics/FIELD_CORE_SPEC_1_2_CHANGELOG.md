# FIELD-CORE — изменения 1.2

11 ноября 2026 года. Решение владельца обновляет продуктовую цель
ROBOTICS-FIELD-CORE-001. Реализация и приёмка остаются будущими обязательствами.

## Решение владельца

Простой доступ даёт готовый робот с настоящей собранной и рассчитываемой схемой.
Расширенный открывает редактирование той же конструкции и цепи. В обоих действуют
общие Arduino/library, electrical solver, реальные устройства, механика и часы.
Предложение педагогического actuator, virtual truth sensors и работы без
электрического расчёта отклонено владельцем. Оно не было принятым кодом или
контрактом 1.1. Прямое управление механикой и скрытый обход цепи запрещены.

## Следующие ограниченные работы

E2 фиксирует mode/kit/circuit/bindings/source и версии без произвольного нового
schemaVersion. E4 даёт UI_ONLY просмотр/lock и решает имя/расположение управления.
E7 квалифицирует реальные kit/control и D02 для обоих режимов. E10 проверяет
сохранение и парную приёмку. Документация не выбирает новую задачу и не расширяет
E1, не закрывает D02 и не объявляет implemented/PASS.

## Совместимость версионных evidence

Архив 1.1 сохранён побайтно без баннера. SHA-256 равен
`297bcc4f48ac3af82f9cf6f85e7dc019a409beb48c7506b75c8efeacb6443a0e`.
Его относительные ссылки разрешаются через immutable base commit
`f72154f0f97dbe59535532e97d72ed9bcd7e3b22` и исходный путь
`docs/product/robotics/FIELD_CORE_SPEC.md` (§20.4 актуального ТЗ).
Replay использует recorded version/hash через архивный blob или оригинальный
commit. Frozen hash нельзя заменять текущим. Старый harness с canonical path
может потребовать отдельный bounded specification-resolution adapter. Такая
несовместимость не является физическим FAIL. Raw, fixtures, hash manifests,
активные worktrees и эксперимент сохраняются без перезапуска.

Контрольная правка уточняет безопасный offline-переход, разрешённый Undo программы/модуля,
разницу measured и estimated команд и stop программы против Pause/Reset опыта.
D02 проверяется ограниченным прототипом до продуктового E7; парная MODE-05
выполняется затем на E7/E10, поэтому цикл зависимостей не создаётся.
Архив 1.1 доступен из истории и не включён в обязательный current context.
