# Игры

`/#/games` — самостоятельная страница портала, доступная аккаунтам и ученикам
с входом по коду класса. В боковой навигации она находится после «Проектов».
Шахматы и шашки представлены двумя крупными карточками; на телефоне — одной
колонкой. Карточка запускает игру без выбора среды и ввода названия проекта.

## Сохранение и совместимость

Игровой прогресс использует существующее защищённое хранилище Project Core.
Перенос в отдельный раздел не удаляет документы, версии, учебные данные или
историю партий и не меняет модель прав. Новые игровые таблицы не требуются.

При запуске выбирается последнее активное личное сохранение нужной игры.
При первом запуске создаётся сохранение с постоянным ключом идемпотентности,
область которого сервер ограничивает текущим владельцем. Повторный запрос и
две вкладки не должны создавать два первых сохранения. Ошибка загрузки списка
не разрешает создавать новое сохранение вместо существующего.

Старые адреса редакторов сохраняются. Возврат из личной игры ведёт в «Игры»,
в том числе после перезагрузки страницы. Учебные ссылки и серверные проверки
доступа продолжают действовать.

## Проектные поверхности

`games/game-catalog.ts` определяет, какие модули являются играми.
Проектный выбор среды, главная страница, личные и классные списки проектов,
галерея и содержимое коллекций исключают эти модули. Полный реестр модулей
остаётся доступен странице игр и серверу. Учебные предметы и административная
аналитика использования игр не удаляются.

## Проверка

- `pnpm test:games` — выбор сохранения, идемпотентность, ошибки загрузки,
  фильтрация каталога и восстановление маршрутов.
- `pnpm e2e:games` — настоящий интерфейс с изолированными ответами API:
  desktop/mobile, первый и повторный запуск, обе игры, reload/back и отказ API.
- `pnpm gate:chess-r1:browser` — дополнительно существующие сценарии шахмат и
  сетевых партий с реальными API и тестовой PostgreSQL.

Снимки `reports/games/` являются результатами теста, а не данными пользователей.
