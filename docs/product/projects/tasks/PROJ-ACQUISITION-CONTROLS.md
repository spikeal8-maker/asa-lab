# Общий запрет получения проектов и личная копия

TASK-PROJ-ACQUISITION-CONTROLS-001, программа211. Один зависимый срез после
принятого PR826; решение владельца DEC121. Контроллер продолжает оставшиеся
Scratch copy, native export, likes и guarded update после этого результата.

## Видимый результат

В «Админ → Публикации» компактный общий переключатель разрешает или запрещает
получение публичных проектов. Выключено по умолчанию; verified platform admin,
version/CAS, существующий административный аудит с actor/before/after/reason/
requestId. Не создавать вторую систему настроек. Общий OFF перекрывает Account,
учителя и StudentSeat, прямой API и старую вкладку; просмотр не выключается.

Автор в существующем управлении публикацией явно включает получение своей
работы; новые и старые публикации default OFF. Нет копии без разрешения автора.
Версионированный server admission не доверяет кнопке или cached DTO; изменение
согласия не меняет immutable document/revision и не публикует черновик.

На компактной публичной странице разрешённый действующий Account или StudentSeat
нажимает «Добавить в мои проекты» для уже поддержанных Electronics/3D public-domain
проектов, получает независимый приватный проект из опубликованной V1, открывает
в существующем редакторе, изменяет, сохраняет и повторно открывает. Личный V2
автора и публичная V1 неизменны. Для Seat действует свежий class/individual
download policy из0274. Учитель Account не обязан переключать workspace.

Права вычисляются сервером из настоящего актёра/сессии/класса. Preserve global
mixed-cookie409; invalid Seat cookie не даёт fallback Account. Не создавать
Account или отдельный copy writer. Existing createWithDraft, idempotency,
exact revision, attribution, protected origin, moderation/revoke и locks остаются.
Все старые поддержанные copy endpoints обязаны учитывать общий и авторский OFF.
Fresh private/no-store actor state не добавляется в anonymous cached projection.
Явный source consent и глобальный флаг не заменяют module/license validation.

## Границы и проверка

Одна forward migration после актуального frontier; принятые SQL неизменны.
Existing settings/audit/admin/source ownership reuse. Global row, identity/class,
source/publication locks имеют согласованный порядок; concurrent OFF/copy имеет
определённый исход, после завершённого OFF новая копия запрещена. Уже созданные
копии и публикации не удаляются. Global OFF не меняет publish policy.

Обязательны независимые Code/Security точного SHA, General и существующие
Public Projects real PG/API/built-browser gates. Matrix: defaults OFF, enable,
author OFF, stale/CAS, non-admin/cross-owner/cross-class/blocked actor, Seat
inherit/allow/deny, admin OFF overrides all, concurrent revoke/OFF/copy, private
draft untouched, repeated idempotency, reopen with real editor. Responsive320/
390/1440, понятные denied/pending/error states и реальный результат без больших
неработающих кнопок. Никаких Games или AI/solver изменений.

Scratch asset-copy, native file formats/download endpoint, CC copy semantics,
likes/ratings и рабочий сервер вне этого среза. Действия не объявлять готовыми
до их отдельной приёмки. No dependency reinstall/relink; local narrow checks
once, heavy builds/PG/browser in GitHub. Автор отчёт/SHA then STOP; контроллер
ведёт программу дальше. Финальный deployment ранее разрешён владельцем.
