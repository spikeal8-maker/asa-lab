# Отдельное исправление baseline сборки Public Projects

Это ограниченная зависимость порученной программы Public Projects. Её выбор и
состояние находятся в Projects lane `docs/execution/current.yaml`.

На `main` до изменений публикации общий code gate отклоняет импорт
`../../tools/web-private-symbols.mjs` из `apps/web/vite.config.ts` как внешнюю
runtime-зависимость. Этот импорт нужен конфигурации сборки: он сохраняет закрытые
символы диагностики и не должен удаляться ради зелёного CI. Причина относится к
категории C по AGENTS.md; она исправляется отдельным исполнителем и отдельным
коммитом, а не включается в продуктовый diff публикации.

Срез ограничен `eslint.config.mjs` и `eslint.boundaries.config.mjs`. Допускается
точное исключение для указанного build-time импорта только в Vite config, общее
для двух конфигураций проверки. Все остальные dependency constraints, запрет
runtime-импорта из `apps/web/src`, encryption/private-symbol pipeline и команда
общего gate сохраняются. Модули, зависимости, deployment и рабочая БД не меняются.

Проверка должна воспроизвести исходный отказ, принять допустимый Vite import и
отклонить тот же импорт из runtime-файла и другой запрещённый import. Требуются
существующие релевантные проверки private-symbol pipeline, независимое review
точного SHA и общий CI. После исправления контролёр возвращается к приёмке
первого видимого среза публикации; завершение этой зависимости не завершает
порученную программу.
