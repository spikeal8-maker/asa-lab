# B2 — отправка жалобы из публичной страницы

Выбрано владельцем в программе завершения Public Projects. Issue [#721](https://github.com/spikeal8-maker/asa-lab/issues/721).
Зависимости приняты: #704 (107bbc6b), #717 (7a6558ca); миграция0259.
Активность и checkpoint — только current.yaml.

## Результат

Доступная публикация → компактное меню `⋯` → «Пожаловаться» → причина и
необязательный комментарий → подтверждённый сервером результат. Одна доступная
с клавиатуры модальная форма, без навигации в редактор. Страница публикации и
действия копирования, Share, редакционного выбора и закрепления сохраняются.

Использовать существующий POST `/api/public-projects/:publicationId/reports`,
текущий revisionId и Idempotency-Key; не создавать другой backend. Причины:
спам, оскорбления, опасное содержимое, персональные данные, авторские права,
другое — с точным соответствием серверным enum. Лимит500 Unicode codepoints,
согласованный с принятой ASCII-space нормализацией B1. При сетевом повторе
сохранять ключ для того же payload; при изменении payload новый ключ.

Guest/StudentSeat и смешанный контекст не получают обхода допуска. Успех только
после валидного receipt; потеря ответа не показывается как успешная отправка.
Ошибки400/401/403/404/409/429/503 объясняются понятным текстом. Не выводить SQL,
технический текст исключений, личность жалобщика или чужие жалобы. Отправка
не скрывает публикацию автоматически.

## Границы

Только Public Projects frontend/API adapter, локальные компоненты/стили и
связанные тесты, подключение browser сценария в профильный gate при необходимости.
Никаких новых SQL, изменений Identity, AI, Electronics, Scratch, общего CI или
административной очереди. B3 и лайки идут после принятой зависимости.
