# 8. Создание и скачивание файлов

## R15. Настоящий Excel и корректный CSV

Добавить общий инструмент таблиц из проверенной структуры: листы, колонки, строки, типы, значения, разрешённое оформление. «Для Excel» означает настоящий XLSX, не переименованный CSV. Строит библиотека экспорта, не свободная строка модели; содержание проверяется до «Готово».

Сохранять кириллицу, ведущие нули, длинные ID, дробные числа, bool и даты с явным типом. Телефон/артикул не превращаются автоматически в число. Формулы допустимы только как явный тип по запросу вычислений. Текст с =, +, - или @ не должен неожиданно исполниться; отрицательное число остаётся числом. Макросы и внешние связи запрещены.

CSV: корректные кавычки/экранирование, переносы, фиксированный разделитель, UTF-8. Явный профиль «CSV для Excel» с BOM и выбранным разделителем; не обещать одинаковую автоинтерпретацию любых региональных настроек. Для обмена — отдельный предсказуемый профиль. Исходные значения и защита формул документируются.

Приёмка: реальный browser download, независимый parser и открытие в Microsoft Excel в согласованной среде. Кириллица, несколько листов, кавычки, переносы в ячейке, нули, длинные ID, числа/даты и опасный текстовый префикс. Без предупреждения о расширении, сдвинутых колонок и потерь. До открытия нельзя писать «проверен в Excel».

## R16. Документы, код и сохранённые артефакты

Сохранить PDF/DOCX/MD/TXT. Word обозначать DOCX, не DOC. Отличать скачивание ответа от создания документа/таблицы по заданию: Markdown-конверсия не означает произвольную профессиональную вёрстку.

Код скачивается с безопасным именем/расширением; HTML/SVG не исполняются в портале. Пути и имена модели нормализуются. Многофайловый проект — явный список и безопасный архив без absolute/traversal paths. Ссылка обязана вести к реальному артефакту.

Самостоятельные документы/таблицы привязаны к операции и владельцу, доступны после reload, имеют имя, MIME, размер, версию и источник. Хранение/удаление согласованы с R25. Повторный экспорт сохранённого текста не вызывает LLM; приватное не отправляется внешнему конвертеру.

Приёмка: байты/содержание всех форматов, имя/MIME, reload, отсутствие лишней модельной операции, отказ чужому owner. PDF открыть и визуально проверить кириллицу, переносы, таблицы; DOCX — читаемую структуру.

# 9. Интерфейс чата

## R17. Компактные действия и меню

Три компактные иконки: копировать, новый вариант, скачать. Без крупных подписанных кнопок «Попробовать снова»/«Скачать ответ». Скачивание — узнаваемая стрелка загрузки, треугольник только дополнительный знак меню.

У кнопок доступные имена, видимый focus, disabled-state, однострочная hover/focus подсказка. Копирование подтверждается кратко. Повтор — явно новая генерация с предупреждением о расходе, без скрытого вызова. Иконка ориентировочно 18–20 px, интерактивная область не меньше 44×44 CSS px.

Desktop: меню сбоку, меняет сторону при нехватке места. Mobile: привязанный popover/компактная панель внутри видимого экрана, без зависимости от hover. Escape/outside click/выбор закрывают меню и возвращают focus. Меню не сдвигает историю и не перекрывает ввод.

| Формат | Однострочное пояснение |
| --- | --- |
| PDF | Документ для просмотра и печати |
| DOCX | Документ для Microsoft Word |
| XLSX | Таблица для Microsoft Excel |
| CSV | Табличные данные для обмена |
| MD | Текст с разметкой Markdown |
| TXT | Обычный текст без оформления |

Предлагать осмысленные форматы: XLSX/CSV только для структуры таблицы или явного создания таблицы. Пока файл формируется, не запускать дубль. Ошибка рядом с действием.

Приёмка: mouse/keyboard/touch, короткий и узкий экран, край окна, несколько ответов, pending/error. Подсказки короткие, меню видно полностью, focus сохраняется.

## R18. Читаемое оформление и адаптивность

Сохранить минималистичный текущий чат, компактный composer, обратимое сворачивание навигации, light/dark. Без второй верхней панели, лишних объяснений пустого экрана и постоянных технических уведомлений.

Иерархия заголовков, интервалы, списки, цитаты, ссылки, таблицы, code blocks и формулы. Безопасная подсветка кода не меняет копируемый оригинал. Ответ модели не может задавать произвольные HTML/CSS/цвета. Цвет — состояние/акцент, не единственный смысловой сигнал.

Таблица/код прокручиваются внутри сообщения, не растягивают страницу. Длинные названия чатов/файлов и несколько вложений не закрывают Send/Stop. Чтение старых сообщений не вызывает принудительную прокрутку вниз. После terminal доступен ввод; focus не похищается у открытого меню/другого поля.

Приёмка: 320/390/768/1024/1440/1920 CSS px, обе темы, 200% browser zoom, экранная клавиатура, длинный код/таблица/формула, четыре вложения. Обязательные реальные снимки 320/390/1024/1440. Evidence другого SHA не заменяет текущую визуальную приёмку.
