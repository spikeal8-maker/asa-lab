# ASA Lab AI — вход исполнителя

[Единое действующее ТЗ v1.1](../ASA_AI_ASSISTANT_SPEC.md) относится только к существующему AI-блоку. Не начинать с исторического PR, старого локального ТЗ или отчёта о прежней сборке.

## Один заход из чата

1. Прочитать корневой `AGENTS.md`, выполнить обычный `pnpm agent:preflight --scope ai-assistant --check` и восстановить выбранную задачу из `docs/execution/current.yaml`. Не повторять полный аудит всего репозитория перед небольшим исправлением.
2. Получить от контролёра ровно один ID ASAI и соответствующую полную карточку из [каталога](PROGRAM_DEFINITION.json), связанные R/C и конкретные разрешения. Наличие списка из 44 задач не разрешает выполнять их все подряд.
3. Подтвердить исходный дефект, реализовать минимальную цельную вертикаль, выполнить применимые проверки и показать работающий результат. Не ограничиваться серверным endpoint, макетом или отчётом о количестве файлов.
4. Отправить короткий результат: **что видно → где открыть → как проверить → evidence и SHA → тесты → ограничения**. После выбранной карточки остановиться. Контролёр отдельно назначает следующий шаг.

Каталог хранит полные специфичные поля каждой задачи: исходную проблему, результат, реализацию, проверки, демонстрацию, зависимости и ограничения. Общие условия вынесены в TASK_CONTRACT, чтобы не поддерживать 44 расходящиеся копии одинаковых правил. Для передачи в отдельный чат контролёр объединяет общий контракт и запись выбранного ID; нельзя передавать только название задачи.

## Видимый результат обязателен

Для изменённого UI: 1440/390 px, светлая/тёмная тема; компактный чат и меню также 320 px. Нужны before/after одного сценария и реальная оценка изображений. Для динамических действий — запись или trace. Снимок с подставленным успешным API не является пользовательской приёмкой.

`CODE`, `CI`, `DEMO`, `IN_MAIN`, `DEPLOYED_TEST`, `OWNER_ACCEPTED` — разные факты. При недоступном показе — `BLOCKED_DEMO`; при недоступной реальной модели — `BLOCKED_PROVIDER`. Проценты готовности без критериев и обещание «UI потом» не закрывают карточку.

Первый рекомендуемый продуктовый результат — ASAI-01, рабочий Обзор ИИ. Срочные исправления ASAI-15 и ASAI-19 независимы от полного завершения админки. Реальный выбор делает контролёр с учётом current.yaml, разрешений и пересечений файлов.

Новые наблюдения получают ID `AI-OBS-YYYYMMDD-NNN`, ожидаемое/фактическое, роль, SHA, воспроизведение и доказательства. Исполнитель не теряет замечание и не расширяет свой scope автоматически.

Исторические отчёты и исходники другого SHA — основания, не текущий PASS. Состояние исполнения не дублируется в этом README или статическом каталоге.
