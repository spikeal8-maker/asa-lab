# CRM program — core card handoff

Bounded slice1 of the owner's full CRM program. No site update or live DB access.
Baseline: Main `4e65ca24ab9bd31f24d4b2384f2d79968d68cb09`.

Implemented:

- Typed Account/StudentSeat full profile and exact links, optional Seat DOB,
  age, actual Account capabilities, workspace memberships and teaching classes.
- Platform-only canonical profile mutation, capability management and Seat
  suspend/restore with expected version, reasons and immutable before/after audit.
  Account DOB preserves18+ eligibility. Seat suspension revokes its sessions;
  it does not revoke a linked personal Account or erase its learning history.
- Full retained paged projects, actual AI message text, sessions and observed
  events. Teacher readers require a current exact-class owner/co-teacher grant;
  they never gain a linked personal Account or another class through tenant.
- Platform-only history saved-version reader and exact owned-project draft /
  version read; saved PNG/WebP screenshot when available, full read-only JSON.
  No editor mutation, user-code execution, password/code/API-secret disclosure.
- Existing Account CRM gains a Full Card tab; Seat gets a full-card launcher;
  teacher learner page gains Card and AI tab. Lazy query, stale/unmount guards,
  profile conflict retains inputs, successful changes invalidate the directory.
- Forward repair serializes existing platform role/status writers before actor
  reauthorization and rejects NULL commands, preventing mutual admin revocation.
