# Классы — первый пакет правок владельца

База: `e2352a99d602c05c42c99be9dea22bb593accdc9`.

## Изменено

- Список учеников добавляется одной кнопкой «Добавить». Автоматически открываются карточки только новых учеников. Повтор после потерянного ответа сохраняет requestId.
- Печать А4: 20 карточек на странице; 30 и 40 карточек занимают две страницы. Коды и сессии печатью не изменяются.
- Уже авторизованный Account открывает ссылку класса и отправляет существующую заявку преподавателю без замены своей сессии.
- В «Мои классы» существующие показатели перенесены рядом с названием, нижний повтор убран.
- Компактная шапка класса, показатели перед вкладками, отдельные «Заявки» и «Настройки». Существующие шкалы и оповещения перенесены в настройки.
- Списки уплотнены без уменьшения шрифтов. Ученики нумеруются после сортировки/поиска; заголовки переключают направление сортировки.

## Проверки

24 unit-теста — PASS. 10 Chromium-сценариев против собранного приложения с синтетическим API — PASS. Проверены одно нажатие, потерянный ответ, 20/30/40 карточек, независимое декодирование QR, размеры и число страниц PDF, ширины 1440/1024/390/320, существующий Account по ссылке. TypeScript, сборка Web без кэша, ESLint изменённых файлов — PASS. PDF дополнительно открыт и отрисован PDFium.

Синтетические браузерные проверки не заменяют PostgreSQL. Реальный API/БД-сценарий добавления 30 учеников, повтора запроса и одобрения заявки Account добавлен в `e2e/student-access-cards.spec.ts`; его результат подтверждается отдельно в GitHub Actions.

Снимки и PDF содержат вымышленные данные из собранного продукта, не дизайн-макет. `127.0.0.1:4612` — перехватываемый тестовый origin; эти карточки не предназначены для ученического входа. Product QR сохраняет origin текущей установки; домен не прошивается.

## Не выполнено этим пакетом

Новый ручной журнал по датам, новые шкалы/категории оценок, рейтинг, счётчик всех работ аккаунта, новая страница участника, роли помощников, дополнительные заслуги и загружаемые аватары. Отдельные проблемы transient StudentSeat logout и архивного класса при enforced storage также не закрываются этим пакетом.

Рабочий сервер, настоящая база, Docker, сеть и опубликованные классы не изменялись. Merge, deployment и независимая приёмка не выполнялись.
