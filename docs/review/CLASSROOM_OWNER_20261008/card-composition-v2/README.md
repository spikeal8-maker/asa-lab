# Карточки доступа — исправленная композиция

Правка владельца: имя ученика, бренд и название класса не должны быть собраны в левом верхнем углу.

Изменён настоящий компонент `apps/web/src/components/StudentAccessCards.tsx` и его `student-access.css`, а не автономный HTML-макет.

- Бренд слева и класс справа в служебной строке.
- Имя ученика по центру отдельной зоны.
- Два блока кодов внизу с выровненными подписями.
- QR и адрес в отдельной правой колонке.
- Обычное имя 14 pt, код ученика 19 pt, код класса 12 pt, подписи 8 pt. Очень длинные подписи имеют отдельный компактный режим; текст не обрезается.
- 20 карточек на А4, две колонки и десять строк. Выбор учеников, коды, class-only QR, происхождение адреса и API не изменены.
