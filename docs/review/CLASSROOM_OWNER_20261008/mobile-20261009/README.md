# Мобильная страница класса — исправление от 09.10.2026

## Что изменено

Настоящий `ClassroomPage.tsx`, отдельный route-scoped CSS и тесты, а не автономный HTML. Верхняя панель на телефоне занимает один ряд; меню, главная, публичные проекты, знания, создание и аккаунт остаются доступны. Краткие подписи не меняют доступные имена команд. Все восемь разделов класса доступны через переключатель; сортировка имеет двенадцать вариантов по существующим шести столбцам.

Статистика собрана в одну полосу. Добавление одного ученика, списка и карточек — в одном ряду. Поиск и сортировка — рядом. Строка ученика имеет две зоны: имя/активность/меню, затем код/сданные задания/безопасный режим. Имена не уменьшены. При отсутствии совпадений в поиске и отказе буфера обмена показано объяснение. Настольная таблица сохранена.
