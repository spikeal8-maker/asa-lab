## Контракт знаний

`GET /api/gallery/knowledge?offset=0&limit=10` возвращает до 10 элементов
`{id,title,summary,authorName,publishedAt,lessonCount}` и `nextOffset`.
Без `limit=10` размер страницы 24; некорректный offset заменяется на 0.
SQL выдаёт только `kind=course AND visibility=public` из существующего
`shared_catalogue`, с устойчивой сортировкой по времени и ID.

`GET /api/gallery/knowledge/:courseId` повторно проверяет опубликованную
видимость в одном SQL-снимке и выдаёт безопасную learner-проекцию опубликованной
версии: разделы и материалы без teacher-only assignment payload. Удалённая
публикация, private и чужой school/shared курс недоступны по прямому URL.
Невалидный ID — 400, отсутствие сессии — 401, недоступный курс — 404.
Переиспользованы существующие session/StudentSeat checks, grants и RLS.

Это каталог для вошедших пользователей, не новая гостевая платформа.
Существующий shared catalogue не включает собственные курсы автора; для
управления ими остаётся «Курсы и задания». Самостоятельная запись на курс,
статьи/видео как отдельные публикации и универсальный inbox — последующие этапы.
