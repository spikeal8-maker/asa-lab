## Результат

- Сохранена компьютерная шапка. «Исследовать» ведёт в существующую галерею
  с прежними правами; личные разделы находятся слева.
- На телефоне — раскрываемое вертикальное меню с настоящими ссылками,
  Escape, возвратом фокуса и недоступным фоном. Слово «Создать» не скрывается.
- Убрана стрелка-кружок на левой аватарке. Меню правого аккаунта, настройки,
  переключение организации и выход сохранены.
- Две полки: 3D-моделирование и Электроника. Не более четырёх недавних работ
  каждой среды и постоянная плитка создания. Игры остаются отдельным разделом.
- «Создать» раскрывает два доступных варианта. Выбор сразу открывает созданный
  редактор, без диалога имени и неработающих «Скоро». Названия назначает сервер:
  «3D модель N» и «Электрическая цепь N». Старые имена не изменены.
- Создание использует общий account/workspace-scoped intent и idempotency key.
  Потерянный ответ, двойной клик и перезагрузка не создают второй проект.
- Серверные module/search/sort/limit/cursor, стабильный порядок с tie-breaker
  по ID, ограниченные ответы без документов. Главная запрашивает до пяти работ
  каждой среды; полный список — страницы по 40. Фильтры и возврат — в URL.
- Фоновые ошибки действий не уничтожают карточки и не включают общий skeleton.
  Ответ старого аккаунта не открывает его проект после смены пользователя.
- Второстепенные страницы загружаются лениво внутри сохранённой оболочки.
  Действующие boot-shell/chunk recovery и приглашения не удалены.
- Уточнены устаревшие утверждения о коллекциях и копировании публикаций в
  `ASA_GALLERY_COLLECTIONS_SPEC.md`. Новая галерея не создавалась.

## Реальные ошибки, найденные проверкой

1. PostgreSQL мог ответить `ROLLBACK` на `COMMIT` после проглоченной ошибки
   необязательного события. Код ранее мог подтвердить несуществующее сохранение.
   Теперь событие изолировано SAVEPOINT, а результат COMMIT проверяется.
   Ошибка восстановления транзакции не подавляется; испорченное соединение
   не возвращается в пул. В логи не попадают документы или персональные данные.
2. Первые focused-тесты не покрывали `SELECT DISTINCT` общего списка. Полный
   прогон обнаружил несовместимость нового ORDER BY с этой веткой. Исправлена
   проекция сортировки и добавлены реальные проверки всех трёх порядков.
3. Прямой HTTP-доступ к собранной SPA через API по LAN IP не запускался:
   `upgrade-insecure-requests` отправлял CSS/JS на отсутствующий HTTPS-порт.
   Для прямых HTTP private-IP/localhost запросов убрана только эта директива.
   Остальные CSP-ограничения сохраняются; публичные hostname и HTTPS сохраняют
   upgrade. Forwarded-host/proto не дают исключение. Это исправление API-выдачи
   SPA; Docker Caddyfile, публичный ingress, DNS и FRP не менялись.

## Измерения

Один production-build сценарий, Chromium, disabled browser cache, пять reload.
Baseline снят до правок; последующий замер снят после совместной сборки.

| Метрика | До | После |
| --- | ---: | ---: |
| Декодированный объём наблюдаемых JS/CSS | 739822 B | 414403 B |
| Переданный объём JS/CSS с HTTP-заголовками | 185408 B | 114709 B |
| Медиана времени до заголовка полки | 207 ms | 197 ms |

Снижение наблюдаемого JS/CSS — около 44%. Последняя строка — лабораторный
индикатор видимости заголовка, не LCP, INP, готовность всех карточек или p75.
Сетевой и аппаратный эффект для реальных пользователей пока не измерен.
Существующие бюджеты чанков не ослаблены; добавлен предел 600000 B для всего
статического entry JS/CSS-графа. Динамические редакторы не считаются стартовым
графом. Запись внешнего MAX SDK с нулевым resourceTiming размером не считается
измеренным объёмом стороннего сервиса.

После четырёх прогревочных проходов выполнены 20 чередующихся возвратов из
3D/электроники. После возврата Workers = 0 во всех проходах. Heap после GC:
19399076 → 20972808 B, DOM nodes 1362 → 1425, listeners 223 → 232 — ниже
зафиксированных regression ceilings. Это ограниченная проверка удержания
ресурсов, не доказательство отсутствия всех таймерных/WebGL утечек.

Снимки и JSON: `e2e/artifacts/owner-preview/home-workspace/{before,after}`.
Файлы автоматически воспроизводятся браузерным тестом, не публикуются как
owner assets. Отдельно сохранены LAN desktop/mobile и ошибка действия.
