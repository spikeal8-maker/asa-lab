# ASA Lab Robotics — поле и стартовая зона (D2-R2, 10 ноября 2026)

## Область работ

- Новое поле по умолчанию 5×5 м через Web и серверную фабрику Project Core.
- Начальная позиция робота — геометрический центр выбранного поля; самостоятельная зона старта 30×30 см, квадрат 300×300 мм с надписью СТАРТ.
- Масса и геометрия: учебные варианты мячей, банок, кубиков; физическая модель и схема электроники остаются общими.
- Редактор поля: плавающая панель свойств, векторные линии/кривые, прямоугольник, круг, текст, маркеры изменения размера, локальное изображение, импорт/экспорт JSON.
- Пересмотрены генерация миниатюр большого поля и контракт публичного просмотра кубика 3 см; затронуты тесты/валидация.
- Действующие сохранённые проекты сохраняют начальные координаты; команда «По центру» предназначена для явного центрирования в старом проекте.

## История проверки

- Локально D2-R2, 127.0.0.1:4630 Web, 4631 API, выделенная PostgreSQL 4632. Другие сервисы не обновлялись.
- Unit: выборочная проверка центрирования и физики 79/79 PASS, стартовая зона 6/6 PASS.
- TypeScript: contexts/robotics и apps/web без ошибок; ESLint по затронутому исходному коду PASS.
- Browser: поле и объектные сценарии, создание и сохранение/повторное открытие проекта 5×5 м, Undo и создание рисунков проверялись локально.
- Начальная расширенная регрессия затронутой ветки: 183/192 PASS; 9 исторических тестов geometry/sonar в двух файлах ещё требуют обновления собственных фикстур и повторной проверки после центрирования.
- CI GitHub и интеграционная квалификация main не считаются пройденными на основании только локальных тестов.
